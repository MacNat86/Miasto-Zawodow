# Miasto Zawodów

Gra edukacyjna dla uczniów klas ósmych: uczniowie pracują w firmach doradczych dla miasta, poznają zawody i ćwiczą współpracę.

## Zawartość

* `index.html` (lub `miasto-zawodow.html`): aplikacja uruchamiana w przeglądarce, bez serwera i bez internetu (poza kodami QR dla telefonów).
* `LICENSE`: prawa autorskie i zasady korzystania.
* `THIRD\_PARTY\_LICENSES.txt`: licencje komponentów zewnętrznych.
